# Research Roadmap Reference

Lộ trình nghiên cứu chính thức của workspace nằm tại:

`../ROADMAP.md`

Đây là bản canonical duy nhất và phải được đọc trước khi thay đổi hướng nghiên cứu.

## Logic cốt lõi

```text
Chuẩn hóa Hospital
→ Nearest closed-loop baseline
→ MapEx closed-loop
→ nhiều run
→ phân tích theo exploration stage
→ log toàn pipeline
→ đánh giá prediction / uncertainty / visibility / IG / ranking / WFD
→ oracle / ablation
→ xác định bottleneck
→ kiểm tra literature
→ chọn research gap
→ đề xuất phương pháp
→ benchmark
```

Nguyên tắc quan trọng: không chọn sẵn uncertainty, visibility, ranking hay WFD làm bài toán nghiên cứu. Trước tiên phải có bằng chứng closed-loop và oracle/ablation chỉ ra bottleneck.

Nếu nội dung file này khác `../ROADMAP.md`, luôn ưu tiên `../ROADMAP.md`.
