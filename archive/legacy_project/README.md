# Legacy TurtleBot4 foundation

Thư mục này chứa phần project TurtleBot4 lịch sử trước khi trọng tâm chuyển sang MapEx research.

Đây là **archive để audit/provenance**, không phải active runtime/research state.

Nội dung chính:

- `.joy/` — Joy project metadata/roadmap/commands lịch sử.
- `PROJECT_STATUS.md` — snapshot trạng thái project cũ.
- `ROOT_README_LEGACY.md` — README root trước khi repo được tổ chức lại theo MapEx.
- `stage3_navigation_benchmark/` — benchmark Nav2 robot thật.
- `evidence/` — evidence các stage kỹ thuật cũ.
- `maps/` — map lab cũ.
- `report/` — báo cáo theo ngày và proposal cũ.
- `docs/`, `data/` — tài liệu và dữ liệu hỗ trợ cũ.
- `legacy_ci/` — validator/workflow CI cũ phụ thuộc cấu trúc Stage 1–5.

Không xóa archive nếu chưa có quyết định riêng về retention/provenance.
