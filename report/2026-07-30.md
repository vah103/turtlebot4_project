## 2. Tạo map mới và khởi động Navigation

### Lệnh chạy

```bash
ros2 run nav2_map_server map_saver_cli \
  -f /home/dell/turtlebot4_project/maps/lab_2026_07_30/lab_map \
  --ros-args \
  -p map_subscribe_transient_local:=true \
  -p save_map_timeout:=10.0 \
  -r __ns:=/bot1

ros2 launch turtlebot4_navigation localization.launch.py \
  map:=/home/dell/turtlebot4_project/maps/lab_2026_07_30/lab_map.yaml \
  namespace:=/bot1

ros2 launch turtlebot4_navigation nav2.launch.py \
  namespace:=/bot1
```

### Log / kết quả

```text
Map size: 168 × 385 pixel
Resolution: 0.05 m/pixel
Map saved successfully
```

Sau khi đặt lại **2D Pose Estimate**, AMCL hội tụ, Nav2 hoạt động ổn định và các goal thủ công được chạy thành công.

## 4. Chạy Navigation Benchmark

### Lệnh chạy

```bash
cd ~/turtlebot4_project/stage3_navigation_benchmark

python3 scripts/navigation_benchmark.py \
  --goals config/benchmark_goals.yaml
```

### Log / kết quả

